- **ไม่มีหน้าแรกแล้ว**: เปิดมาเข้าเกมเลย (เกิดในเมืองที่อยู่ล่าสุด) · ปุ่ม "เริ่มใหม่" ย้ายไปอยู่ใน Engine settings · Esc = ปิด settings · ปุ่มเมนูบนแถบด้านบนเอาออก · โค้ดหน้าแรก (`drawTitle`, keyart) ลบออกแล้ว — `assets/art/keyart.jpg` ยังอยู่แต่ไม่ได้ใช้
- **โลกเปิดต่อกัน** (`world/overworld.*`, `world/layout.h`): หมู่บ้านหิมะอยู่ที่ (0,0), เมืองยุคกลางย้ายไปอยู่ทางใต้ (ศูนย์กลาง (0,250) หมุน 180° ให้ประตูเมืองหันมาหาหมู่บ้าน), ตรงกลางเป็น **The Wilds**
  - ถนนสายเก่า (โคมไฟทุก 14 ม., ป้ายบอกทาง) จากประตูใต้หมู่บ้าน (0,36) → ประตูเมือง (0,198) · ขอบแมพ/กำแพงเมืองเปิดช่องให้เดินผ่าน (`layout::corridor`)
  - แม่น้ำ (`riverX`) จาก Spring Pond (ท่าเรือ + เรือรออยู่) → Citadel Harbour · พายเรือข้ามได้ (E ที่ท่า)
  - ม้าโพนี่ Cube World รอที่ปลายถนนทั้งสองฝั่ง (ขี่ข้ามเขตได้เพราะใช้ฟิสิกส์ของ Overworld) · แกะ, อัลปาก้า, กระท่อมชาวประมง
  - ป่าสนหิมะ → ป่าโอ๊ค, จุดพักกองไฟ (Wayfarer's Camp), หิมะค่อยๆ เปลี่ยนเป็นหญ้า (texture blend `map2`), แสง/หมอก/ท้องฟ้า blend ตามตำแหน่ง
  - มินิแมพแบบ wilds, ชื่อโซนใหม่ใน `config.h`
- ซุ้มประตูกาลเวลาไม่วาร์ปแล้ว (เป็นประตูเฉยๆ) · ปุ่มบนแถบด้านบนยังเป็นทางลัดไปอีกเมือง · ถ้ำคริสตัลยังวาร์ปเหมือนเดิม
- ระบบพิกัด: ผู้เล่น/สัตว์เลี้ยง/เรือ/เชอร์รี่ = global · parkour, พุ่มเบอร์รี่, บ้าน/สัตว์ Cube World ในเมือง = local ของเมือง (แปลงด้วย `Overworld::toLocal/toGlobal`) · net ส่ง local + realm เหมือนเว็บ (เล่นข้ามกับเว็บได้)
- `--auto e` = กด E ครั้งเดียว (ทดสอบขึ้นเรือ/ขี่ม้า)
- **กระแสน้ำ** (`World::waterFlow`, Overworld): แม่น้ำไหลลงใต้ 0.7 ม./วิ + ดึงเรือเข้ากลางร่อง + หัวเรือค่อยๆ เลี้ยวตามแม่น้ำ (ทั้งขาไปขากลับ) — ทดสอบ: กดเดินหน้าอย่างเดียว เรือจาก Spring Pond (z 90) ถึง Harbour (z 174) ใน ~25 วิ
- **Willow Bridge** (`Overworld::buildBridge`, `layout::BRIDGE_Z`): สะพานไม้โค้งข้ามแม่น้ำข้างจุดพักกองไฟ (z 128) — เดินบนสะพานได้ (ground fn นับเฉพาะเมื่ออยู่ใกล้พื้นสะพาน), เรือ/คนว่ายน้ำลอดใต้สะพานได้, มีชื่อโซน `bridge`
- **พุ่มเบอร์รี่ใน wilds** (`Overworld::placeBerries` → `berrySpots`, พิกัด global): 16 พุ่ม ครึ่งหนึ่งอยู่ฝั่งตะวันออกของแม่น้ำ (ต้องข้ามสะพาน) · seed 4242 แยกจาก `rand_` ป่าไม้จึงไม่เปลี่ยน
- **พื้นบล็อกแบบ Cube World** (`world/terrain.*`, 2026-10-11) — แก้ปัญหาพื้น 3 ชิ้นต่อกันไม่สนิท (มีรู/ขอบแหว่งตรงรอยต่อ)
  - พื้นทั้งโลก (หมู่บ้าน + Wilds + เมือง) เป็น mesh บล็อกชิ้นเดียว สร้างใน `Overworld::buildTerrain` · ด้านบนที่เท่ากันรวมเป็นแผ่นใหญ่ (greedy) · ด้านข้างมีเฉพาะที่เพื่อนบ้านต่ำกว่า · ขอบโลกเป็นกำแพงลงไปถึงฐาน
  - กริด `layout::BLOCK` = 0.45 ม. ใน global · `heightAt` ทุกที่ (`winter::`, `medieval::`, `layout::wildsHeight`) สุ่มรูปร่างดิบ (`rawHeight`/`wildsRaw`) ที่กลางช่อง แล้วปัดเป็นบล็อก (`layout::toBlocks`) → ฟิสิกส์เดินบนบล็อกที่วาดพอดี (ขึ้นทีละขั้นอัตโนมัติ)
  - ไม่มีบล็อกที่ผิวพอดีระดับน้ำ (−0.45) — ตลิ่งยกเป็น 0, ก้นน้ำลงไป −0.9 (กันภาพกระพริบ)
  - เลือกพื้นที่ของพื้นด้วยช่องบล็อก (`Overworld::groundAreaAt`) ไม่ใช่จุดจริง → รอยต่อระหว่างพื้นที่ไม่มีขั้นแปลกๆ
  - ผิวบล็อก: `World::surfaceAt` (หิมะ/หญ้า/หิน cobble/ดิน/หิน) + tint · ใต้น้ำเป็นทราย · ต่างกัน ≥ 3 บล็อก = หน้าผาหิน · ข้างบล็อก: ชั้นบนสุดสีเดียวกับผิว ชั้นล่างเป็นดิน/หิน · Wilds หิมะเปลี่ยนเป็นหญ้าเป็นหย่อมๆ
  - เปลี่ยนจากเว็บ: ภูเขาออโรร่าขั้นละ 2 บล็อก (0.9 ม. แทน 1.1) และไม่มี mesh ขั้นบันไดแยกแล้ว · ทะเลสาบน้ำแข็งวางบนพื้นเรียบ (`ICE_Y` 0.04) · ลานหินกลางเมืองเป็นบล็อก cobble แทนแผ่นวงกลม · ลบ `buildGround`/`buildMountain`/`ground()` เดิม
  - พื้นไม่ทอดเงา (รับเงาอย่างเดียว) — เปิดแล้ว FPS ลดครึ่ง
  - ต้นไม้/พุ่มเบอร์รี่ยืนบน `layout::footHeight` (ช่องต่ำสุดใต้ราก, จมได้ไม่เกิน 2 บล็อก) — ไม่ลอยเหนือขั้นล่าง
- **ลดหน่วยความจำ** (2026-10-11): footprint ตอนเล่น 920 → ~640 MB
  - `Texture::upload` ใช้ storage เดิมเมื่อขนาดเท่าเดิม (`glTexSubImage2D`) + `TextureOptions::maxSize` ย่อรูปใหญ่ (`baked.jpg` 4096 → 1024, texture ใน glTF ≤ 2048)
  - HUD: อัปโหลด pixel ของ canvas ตรงๆ แบบ premultiplied (`Canvas2D::uploadPremultiplied`, blend `GL_ONE`) ไม่มี mipmap · สลับ texture 2 ใบ (เขียนใบที่ GPU ใช้อยู่จะทำให้เฟรมรอ — FPS ตกเกือบครึ่ง)
  - `Geometry`: หลังอัปโหลดครั้งแรกปล่อย array ฝั่ง CPU ทิ้ง · normal/สีเป็น byte · index 16-bit — geometry ที่แก้ทุกเฟรมต้องตั้ง `dynamic = true` ก่อนวาดครั้งแรก (ดอกไม้ไฟ, ไฟในห้อง, ธงบนยอดเขา)
  - `CubeWorld::releaseSources()` ทิ้งโมเดลต้นฉบับหลังสร้างโลก (โหลดใหม่เองถ้าต้องใช้) · หน้าต่างไม่มี depth buffer (ฉาก 3D มีของตัวเอง)
  - ที่เหลือส่วนใหญ่เป็นบัฟเฟอร์หน้าต่าง Retina + สำเนา texture ที่ OpenGL ของ Apple ถือไว้ · ถ้าจะลดอีก: ปิด Retina (HUD จะเบลอ) หรือ scene target เป็น R11G11B10F (เสี่ยงท้องฟ้าเป็นแถบสี)
- **ระบบต่อสู้แบบ Cube World** (`game/combat.*`): มอนสเตอร์อยู่เฉพาะใน The Wilds (เดินเข้าเมืองแล้วเลิกไล่ — เมืองปลอดภัย)
  - แคมป์ (`camps()`): Frost Slime/Slime/Gnoll ฝั่งตะวันตก · หมาป่า + **Ogre Lv 8** (บอส) ฝั่งตะวันออกของแม่น้ำ · กลางคืนมี Skeleton + Bat เพิ่ม · ตายแล้วเกิดใหม่ใน 45 วิ (ตอนผู้เล่นไม่อยู่ใกล้)
